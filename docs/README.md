## 18家机场测评

- 1. [Flybit](reviews/flybit.md)：把日常月付和低频按量分开选
- 2. [西游云](reviews/xiyou.md)：低月费先入门，专线权限单独比较
- 3. [CocoDuck](reviews/cocoduck.md)：关注家宽落地，先把常规套餐和加油包分开
- 4. [灵动云](reviews/lingdong.md)：先确认官方客户端，再挑月付或年内小包
- 5. [老猫云](reviews/laomao.md)：有协议变更记录，订阅兼容性要走在价格前面
- 6. [WgetCloud](reviews/wgetcloud.md)：高价档的差别，要落到节点与在线IP权限
- 7. [MESL](reviews/mesl.md)：面板价格为主，区域优化与普通套餐分开比较
- 8. [星辰云（星辰机场）](reviews/xingchen-cloud.md)：低价入口与IEPL档位，要各看一遍
- 9. [极客云](reviews/jike-cloud.md)：同样是月付，IPLC权限从标准版开始看
- 10. [飞鸟云](reviews/feiniaoyun.md)：价格很低，IPv6与Hysteria2配置先过关
- 11. [妙妙云（秒秒云）](reviews/miaomiao-cloud.md)：把每档在线设备数和流量一起算清楚
- 12. [飞兔云](reviews/feituyun.md)：月付、不限时与年付都有，先核对地区限制
- 13. [扬帆云](reviews/yangfanyun.md)：LV等级同时改变设备数和专线权限
- 14. [动力港](reviews/dongligang.md)：8元入门与大流量之间，覆盖规则尤其要看
- 15. [XSUS](reviews/xsus.md)：10元168GB起，续费与流量重置分开看
- 16. [CyberGuard机场](reviews/cyberguard.md)：先用基础流量比较，不把限时翻倍算成常态
- 17. [自由猫](reviews/freecat.md)：低价档很轻，但客户端和用途限制更关键
- 18. [极速云](reviews/jisu-cloud.md)：先除以倍率，再判断额度是否真的够用
